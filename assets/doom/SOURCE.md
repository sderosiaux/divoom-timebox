Status-bar face sprites from Freedoom (https://freedoom.github.io/), taken from
`graphics/` at github.com/freedoom/freedoom. BSD 3-clause; see the project for
the full text.

Freedoom's faces are original art in the shape of Doom's mugshot, so they carry
the same naming (`stfst<tier><gaze>`, `stfouch<tier>`, `stfevl<tier>`,
`stfgod0`, `stfdead0`) and the same 24x29 geometry, but none of id Software's
pixels.
